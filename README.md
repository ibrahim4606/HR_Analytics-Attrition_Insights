🔷 Title: HR Analytics – Attrition Insights (Power BI Project)

📘 Description:
  This project analyzes employee data to understand the key factors contributing to attrition within an organization.Using Power BI, SQL, and Excel, the dataset was cleaned, transformed, and visualized to provide meaningful insights for HR decision-making.The dashboard highlights important metrics such as attrition rate, job satisfaction, salary range, and department-wise turnover.It helps identify high-risk groups of employees and supports data-driven strategies to improve retention.

🛠️ Tools & Technologies:

  🔴 Power BI

  🔴 MySQL

  🔴 Microsoft Excel

  🔴 DAX (Data Analysis Expressions)

  🔴 Power Query Editor

📊 Key Features:

  🔴 Interactive dashboard with filters and slicers

  🔴 Calculated measures using DAX (e.g., Attrition Rate, Avg Salary, Job Satisfaction)

  🔴 Insights on employee attrition by department, gender, and experience

🎯 Outcome:

  🔴 Discovered patterns in attrition behavior

  🔴 Improved understanding of business analytics using Power BI

  🔴 Strengthened data visualization and reporting skills
